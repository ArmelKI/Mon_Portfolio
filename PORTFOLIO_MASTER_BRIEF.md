- Label : `Mobile & Backend · MVP personnel avancé`.
- Titre : `Ankata — réserver un trajet dans une seule application`.

**Product playground d'ingénierie** : un portfolio personnel qui rend la construction logicielle tangible, énergique et facile à explorer. Les systèmes, interfaces et décisions restent les preuves principales ; la couleur sert à orienter la lecture et à donner une identité mémorable.

## 16. Animations recommandées

- Hero : apparition initiale courte, 300–500 ms, opacité + translation 8–16 px.
- Featured : reveal au premier passage seulement ; média et texte peuvent entrer en léger décalage.
- Survol média : translation/scale maximale 1–2 %, sans boucle.
- Architecture : lignes ou nœuds peuvent se révéler une fois pour expliquer `App → API → PostgreSQL`.
- Changement de langue : transition instantanée ou fondu <150 ms, sans recharger la page.
- Navigation : soulignement/repère actif.
- Interdit : bounce permanent, ping, texte tournant, marquee infini, particules, cursor custom, parallax fort, animations déclenchées à chaque scroll.
- Implémenter `MotionConfig reducedMotion="user"` si Framer Motion est conservé.
- Pour `prefers-reduced-motion: reduce`, supprimer transforms, mouvements de fond et smooth scroll ; conserver seulement les changements d'état nécessaires.
- Limiter le suivi du pointeur au Hero et aux appareils `pointer:fine`, puis suspendre hors viewport.
